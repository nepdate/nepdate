# @nepdatejs/styles

[[toc]]

The stylesheet for the components. It's plain CSS.

| Import | Contains |
|---|---|
| `@nepdatejs/styles` | Tokens and components |
| `@nepdatejs/styles/tokens.css` | The `--ndp-*` variables only |
| `@nepdatejs/styles/picker.css` | The component styles only |

See [Theming](/guide/theming) for every token, and [Markup and classes](/guide/markup) for the
classes.

## Classes

`ndp-field`, `ndp-input`, `ndp-input__control`, `ndp-input__actions`, `ndp-input__switch`, `ndp-hint`,
`ndp-range`, `ndp-datetime`, `ndp-input--time`, `ndp-panel`, `ndp-panel__body`, `ndp-panel__footer`,
`ndp-calendar`, `ndp-calendar__header`, `ndp-calendar__title`, `ndp-grid`, `ndp-weekday`, `ndp-day`,
`ndp-option`, `ndp-options`, `ndp-presets`, `ndp-preset`, `ndp-time`, `ndp-time-item`, `ndp-segment`,
`ndp-button`, `ndp-icon-button`, `ndp-holiday-tag`.
